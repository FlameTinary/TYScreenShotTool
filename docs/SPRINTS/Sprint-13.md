# Sprint 13 - 截图工具栏基础

## Status

Completed

## Goal

在 Sprint 12 已完成 `保存目录配置` 的基础上，
开始进入 V0.4 的第一步能力：

Screenshot
→ Toolbar Editing
→ Copy / Save / Cancel

本次目标不是完整截图编辑器，
而是先打通截图完成后的最小工具栏主链路。

---

## Scope

### Included

- 框选完成后进入截图编辑态
- 不再自动执行复制、保存或 OCR
- 增加底部工具栏
- 支持手动复制
- 支持手动保存到默认目录
- 支持取消本次截图
- 增加顶部悬浮设置栏
- 显示当前截图尺寸
- 提供圆角开关
- 提供阴影开关

### Out of Scope

- 矩形、圆形、箭头标注
- 自由画笔
- 文字标注
- 马赛克
- 编号
- OCR 工具栏入口
- Pin 固定截图
- 滚动长截图
- AI 分析

---

## Implementation

### 方向

优先采用最小实现：

1. 先把截图结果保留在当前会话中
2. 框选完成后展示截图结果与底部工具栏
3. 复制、保存改为用户主动触发
4. 顶部悬浮设置栏仅提供尺寸、圆角、阴影三项最小能力

---

### 约束

- 遵循 MVP
- 遵循 KISS
- 遵循 YAGNI
- 不引入复杂截图编辑架构
- 不提前实现后续标注、OCR、Pin、长截图、AI 能力

---

## Validation

### 场景 1

用户完成一次截图后，
不会立刻自动复制、保存或 OCR，
而是先看到截图编辑态与底部工具栏。

### 场景 2

用户点击复制后，
截图可以成功写入剪贴板。

### 场景 3

用户点击保存后，
截图可以成功保存到默认目录。

### 场景 4

用户点击取消后，
本次截图不会复制也不会保存。

### 场景 5

顶部悬浮设置栏能够显示当前截图尺寸，
并提供圆角、阴影两个最小开关。

---

## Result

Done

已完成：

- 框选完成后不再自动复制、保存或 OCR
- 截图进入预览编辑态，并展示底部工具栏
- 支持用户主动执行复制、保存、取消
- 增加顶部悬浮设置栏，显示尺寸并提供圆角、阴影开关

- 导出前会临时隐藏 overlay，避免白色选区描边进入最终截图

- 工程编译通过
- 手动截图流程正常
- 点击保存后桌面成功生成 PNG

- 圆角、阴影在最终导出文件中生效
- 控制台输出保存成功日志
- 连续多次热键截图无需额外点击即可开始框选
- 最终导出 PNG 不再包含白色选区边框
