# Sprint 40 - 工具栏 SF Symbols

## Status

Done

## Goal

将截图编辑态工具栏升级为以 SF Symbols 为主的混合工具栏，
为标注工具增加明确的青色选中态与轻量反馈动画，
同时保留 `长截图` / `OCR` / `AI` 的文字按钮表现，
并保持截图、标注、OCR、AI、Pin、复制、保存、长截图等主链路行为不变。

---

## Scope

### Included

- 6 个标注工具按钮改为 SF Symbols 图标
- 撤销 / Pin / 复制 / 保存 / 取消 改为 SF Symbols 图标
- `长截图` / `OCR` / `AI` 保持文字按钮
- 标注工具选中态改为青色高亮
- 标注工具选中时增加轻量反馈动画
- 工具栏采用单一容器 + 透明按钮风格
- 为每个按钮提供 hover 提示
- 保持工具栏容器沿用当前 `NSVisualEffectView(material: .popover)` 样式

### Out of Scope

- 不修改拖拽选区逻辑
- 不修改标注绘制逻辑
- 不修改 OCR / AI / Pin / 复制 / 保存 / 取消 的业务行为
- 不修改长截图面板 UI
- 不为工具栏新增快捷键
- 不引入第三方依赖

---

## Implementation

### 方向

本轮继续沿用 `CaptureOverlayView` 的 AppKit 结构：

1. 在 `AnnotationTool` 中新增 `symbolName`
2. 在 `CaptureOverlayView` 中重写工具栏按钮创建逻辑
3. 将工具栏布局切换为图标按钮 + 文字按钮混合布局
4. 为标注工具增加青色选中态
5. 清理按钮标题本地化更新，改为 hover 提示与无障碍标签更新

### 约束

- 遵循 MVP
- 遵循 KISS
- 遵循 YAGNI
- 不将现有截图编辑态重构为 SwiftUI
- 不扩展为第二套工具栏系统

### 当前实现说明

- `NSButton` 在当前 AppKit 路径下不能直接套用计划中的 `addSymbolEffect` 按钮动画接口
- 因此当前实现采用 AppKit 可用的轻量反馈动画作为替代：
  - 缩放
  - 透明度变化
- 视觉目标仍然保持“选中时有明确反馈”，但实现方式以当前可编译、可运行路径为准
- 原生 `toolTip` 在截图覆盖层窗口中不可稳定显示
- 因此当前实现改为自定义 hover 提示气泡，由工具栏按钮悬停事件驱动显示

## Result

### 实现

- 标注工具新增 SF Symbols 映射：
  - 矩形 `rectangle`
  - 圆形 `circle`
  - 箭头 `arrow.up.right`
  - 画笔 `pencil.and.scribble`
  - 马赛克 `rectangle.pattern.checkered`
  - 文字 `square.and.pencil`
- 撤销 / Pin / 复制 / 保存 / 取消 切换为 SF Symbols 图标按钮
- `长截图` / `OCR` / `AI` 保持文字按钮，避免识别成本上升
- 工具栏调整为单一毛玻璃容器 + 透明按钮风格
- 标注工具选中态改为青色高亮，并增加轻量缩放 / 透明度反馈
- 重复点击同一个标注工具时保持选中状态，不再反选
- 为截图覆盖层补充自定义 hover 提示气泡，解决原生 `toolTip` 不可见问题
- 清理工具栏标题本地化更新逻辑，改为刷新 hover 提示与无障碍标签

### 验证

- `./scripts/build.sh` 构建通过
- 工具栏图标与文字按钮混合样式人工验证通过
- 标注按钮选中态与重复点击保持选中人工验证通过
- hover 提示人工验证通过

### 结果

Sprint 40 完成后，截图编辑态工具栏完成了一轮原生风格收口：
常用标注与主要动作变得更紧凑、可扫读，
同时保留了 `长截图` / `OCR` / `AI` 这类更适合文字表达的入口，
整体交互清晰度和视觉一致性都有所提升。
