# Sprint 26 - 长截图增强

## Status

Completed

## Goal

在现有最小滚动长截图能力基础上，
补齐自动追加、底部结果操作与实时预览能力，
提升长截图连续滚动过程中的可用性。

---

## Scope

### Included

- 支持滚动过程中自动追加当前屏
- 长截图操作面板调整为截图边框底部结构
- 长截图操作面板提供 `取消`、`保存`、`复制`
- 在截图边框左右可用空间更大的一侧实时显示当前长图预览
- 长图预览根据可用空间自适应尺寸，尽量完整显示内容
- 保持与现有长截图白框边界提示衔接

### Out of Scope

- 修改普通截图冻结链路
- 修改现有标注、马赛克、圆角、阴影与截图区域微调主链路
- 引入复杂滚动策略配置页
- 引入历史记录管理
- 引入 AI 分析

---

## Implementation

### 方向

优先采用最小实现：

1. 先打通长截图滚动自动追加主链路
2. 再补齐底部结果操作与实时预览
3. 预览位置优先根据左右剩余空间自适应布局
4. 不提前扩展复杂滚动参数配置

### 实际完成

1. 长截图从手动追加切换为滚轮事件驱动追加
2. 长截图保留白框边界提示，同时允许底层页面真实滚动
3. 长截图操作面板收敛为 `取消 / 保存 / 复制`
4. 新增侧边实时长图预览，并根据截图边框所属屏幕的左右可用空间自适应布局
5. 长截图结果可直接复制或保存，不再依赖旧的“完成长截图结果态”主交互
6. 拼接缝增加二次优化，优先尝试将 seam 放在空白或低干扰位置

### Future Improvements

- 在高密度文本场景下继续增强 seam 搜索策略，进一步降低半截文字概率
- 微调滚轮事件后的抓帧延迟，尽量避开滚动动画尚未稳定的中间态

### 约束

- 遵循 MVP
- 遵循 KISS
- 遵循 YAGNI
- 不提前实现 AI 分析

---

不需要手动点击“追加当前屏”。

### 场景 2

长截图过程中，
截图边框左右可用空间更大的一侧可实时显示当前已拼接的长图预览。

### 场景 3

长截图模式下白框边界仍持续可见。

### 场景 4

长截图过程中，
截图边框底部可正常执行 `取消`、`保存`、`复制`。

### 场景 5

长图预览会根据可用空间自适应尺寸，保证内容尽量完整显示。

### 场景 6

普通截图、标注、复制、保存、`OCR`、`Pin` 主链路保持正常。

## Result

Completed

长截图增强主链路已完成：

- 自动追加改为由真实滚轮事件驱动
- 长截图预览可实时增长
- 长截图底部操作收敛为 `取消 / 保存 / 复制`
- 多轮人工验证后，长截图体验与拼接质量均有明显提升
