# Sprint 51 - 长截图工具栏与预览布局优化

## Status

✅ Done

## Goal

优化长截图工具栏的图标化体验和长截图预览窗口布局，减少预览窗口遮挡选区与工具栏的概率。

---

## Scope

### Included

- 长截图工具栏改为 SVG 图标按钮
- 长截图工具栏宽度根据按钮数量自适应
- 长截图工具栏支持 Hover Tooltip
- Tooltip 支持防抖和顺序管理
- 长截图面板保持常驻，减少频繁 `orderOut` / `orderFront`
- 长截图预览窗口同时避让选区与工具栏区域
- 基于选区与工具栏合并区域计算左右可用空间

### Out of Scope

- 不重写长截图拼接算法
- 不修改长截图 OCR / AI / 翻译业务链路
- 不新增新的预览窗口样式
- 不改变普通截图工具栏行为

---

## Implementation

### 实现

- 长截图工具栏按钮统一切换为 SVG 图标按钮
- 工具栏宽度根据按钮数量自适应
- 工具栏接入 Hover Tooltip
- Tooltip 增加防抖和顺序管理
- 长截图面板保持常驻，避免频繁 `orderOut` / `orderFront`
- 长截图预览窗口布局从仅避让 `selectionRect` 升级为同时避让选区与工具栏区域
- 预览窗口基于选区与工具栏合并区域计算左右可用空间，减少遮挡工具栏按钮

---

## Validation

1. 长截图工具栏图标按钮显示正常
2. 工具栏宽度可随按钮数量自适应
3. Hover Tooltip 显示、隐藏、防抖行为正常
4. 长截图面板保持稳定，不频繁闪烁
5. 预览窗口优先避让选区与工具栏合并区域
6. 左右空间不足时预览窗口仍保持可用
7. 长截图保存、复制、OCR、AI 主链路不回退

---

## Result

Sprint 51 完成后，长截图工具栏完成图标化和 Tooltip 化，预览窗口布局从只避让选区升级为同时避让选区与工具栏区域，长截图操作时遮挡关键按钮的概率降低。
