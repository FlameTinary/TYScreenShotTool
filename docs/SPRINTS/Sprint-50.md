# Sprint 50 - 文字标注与工具栏体验增强

## Status

✅ Done

## Goal

增强文字标注的悬停、选中、移动和编辑输入体验，并将普通截图工具栏中的长截图、OCR、AI 入口升级为图标按钮和 Hover Tooltip。

---

## Scope

### Included

- 文字标注支持悬停、选中移动、编辑输入三态交互
- 文字编辑框随内容动态扩展
- 关闭文字标注自动换行，避免短文本被不必要折行
- 修复文字标注边框拖拽、首次点击拖拽与边框适配问题
- 普通截图工具栏补齐长截图、OCR、AI 的 SVG 图标按钮
- 普通截图工具栏支持 Hover Tooltip
- 修复工具栏布局递归和约束冲突

### Out of Scope

- 不新增富文本编辑
- 不新增字体面板
- 不新增多文本批量编辑
- 不修改长截图工具栏

---

## Implementation

### 实现

- 文字标注新增悬停、选中移动、编辑输入三态行为
- 文字标注编辑框支持随文字内容动态扩展
- 关闭文字自动换行以避免短文本不必要折行
- 修复文字标注边框拖拽、首次点击拖拽和边框适配问题
- 普通截图工具栏新增长截图、OCR、AI 的 SVG 图标按钮
- 普通截图工具栏接入 Hover Tooltip
- 收口工具栏布局递归和约束冲突问题

---

## Validation

1. 文字标注悬停态反馈正常
2. 文字标注选中后可移动
3. 文字标注可进入编辑输入态
4. 编辑框随内容动态扩展
5. 短文本不发生不必要折行
6. 普通截图工具栏长截图、OCR、AI 图标显示正常
7. Hover Tooltip 显示正常
8. 工具栏布局无明显约束冲突

---

## Result

Sprint 50 完成后，文字标注从基础输入能力升级为可悬停、可选中移动、可稳定编辑的完整交互；普通截图工具栏也进一步完成图标化与 Tooltip 体验增强。
