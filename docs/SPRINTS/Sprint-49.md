# Sprint 49 - 马赛克标注选中交互与属性面板联动

## Status

✅ Done

## Goal

补齐马赛克标注的选中、缩放和属性面板联动能力，使其与矩形、椭圆、线条、箭头等工具保持一致的编辑体验。

---

## Scope

### Included

- 马赛克标注选中后显示青色虚线边框和 8 个控制节点
- 支持拖拽控制点调整大小
- 支持整体移动马赛克标注
- 修复马赛克选中后属性面板不联动的问题
- 属性面板大小滑块和马赛克 / 毛玻璃模式切换实时生效

### Out of Scope

- 不新增新的马赛克算法
- 不新增多选编辑
- 不修改其他标注工具属性面板
- 不修改 OCR / AI / 长截图主链路

---

## Implementation

### 实现

- 选中马赛克标注后在虚线边框外增加 8 个白色圆形控制节点
- 控制节点绘制复用 `resizeControlPoints(for:)`
- 修复 `mosaicInteraction` 不检查 `selectedAnnotationIndex` 的问题
- 马赛克选中交互与矩形、椭圆、线条、箭头保持一致
- 第一击点击马赛克时正确触发 `onAnnotationSelected`
- 属性面板通过 `updateSelectedAnnotationProperties(.mosaic(properties))` 实时更新选中标注
- 大小调整、马赛克 / 毛玻璃模式切换可实时生效

---

## Validation

1. 马赛克标注选中后显示虚线边框和 8 个控制节点
2. 第一击点击马赛克可正确选中
3. 拖拽控制节点可调整大小
4. 拖拽标注主体可整体移动
5. 属性面板大小滑块实时影响选中马赛克
6. 马赛克 / 毛玻璃模式切换实时生效
7. 自动化测试通过，历史记录为 `142` 个测试通过

---

## Result

Sprint 49 完成后，马赛克工具补齐了完整选中编辑体验，并修复了与属性面板不同步的问题。
