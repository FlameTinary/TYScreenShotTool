# 需求文档：隐藏 AI 入口，新增纯本地截图翻译功能

## 一、需求背景

当前 macOS 截图 App 中已经接入了 AI 大模型相关能力，例如 AI 分析、AI 翻译等。

但 AI 大模型能力涉及法律合规、服务地区、用户隐私、网络传输、模型服务商、备案、订阅等问题。当前阶段不希望默认向用户暴露 AI 相关入口。

因此需要调整产品入口：

1. 默认隐藏普通截图工具栏中的 AI 入口。
2. 默认隐藏长截图工具栏中的 AI 入口。
3. 在普通截图工具栏和长截图工具栏中新增一个普通的「翻译」按钮。
4. 新增的「翻译」按钮不调用 AI、不调用后端、不发起网络请求。
5. 点击「翻译」后，走纯本地流程：

   * 复用项目中已有的 OCR 服务识别截图文字
   * 使用本地翻译能力翻译文字
   * 弹出翻译结果窗口
   * 用户可以预览和复制原文、译文
6. 在设置界面中增加一个开关，用于控制 AI 入口显示或隐藏。

---

## 二、核心目标

实现一个默认合规压力更低的截图翻译入口。

最终用户体验如下：

```text
用户完成普通截图或长截图
  ↓
截图结果工具栏出现
  ↓
工具栏中默认不显示 AI 入口
  ↓
工具栏中显示普通「翻译」按钮
  ↓
用户点击「翻译」
  ↓
App 使用已有 OCR 服务本地识别截图文字
  ↓
App 使用系统本地翻译能力翻译识别出的文字
  ↓
弹出翻译结果窗口
  ↓
用户可以查看识别原文、翻译结果，并复制内容
```

项目中已经存在 OCR 服务。

本需求不需要重新实现 OCR，不需要新增重复的 OCR 服务。

请在项目中查找现有 OCR 相关实现，例如可能存在以下命名：

```text

VisionOCRService
TextRecognitionService
ImageTextRecognitionService
TextRecognizer
ScreenshotOCRService
RecognizeTextService
AIAnalysisOCRService
```

如果已有 OCR 服务目前用于 AI 分析流程，请复用其中“从截图图片识别文字”的能力。

本需求只要求：

```text

  ↓

  ↓

```

## 五、纯本地翻译流程

### 1. 流程总览

```text
用户点击「翻译」按钮
  ↓
获取当前截图图片
  ↓
调用项目已有 OCR 服务
  ↓
获得 OCR 文本
  ↓
如果 OCR 文本为空，展示提示
  ↓
如果 OCR 文本不为空，调用本地翻译服务
  ↓
获得翻译结果
  ↓
打开翻译结果窗口
```

---

### 2. 获取当前截图图片

点击「翻译」按钮后，需要获取当前截图对应的图片对象。

优先复用当前截图结果中已经存在的图片数据，例如：

```swift
CGImage
NSImage
Data
```

如果当前工具栏上下文已经持有截图图片，请直接使用。

不要重新截图。

不要重新触发截图流程。

不要从磁盘重新读取，除非当前架构只能通过已保存文件获取图片。

---

### 3. 调用已有 OCR 服务

本需求中 OCR 服务已经存在。

请直接调用项目已有 OCR 服务。

目标能力是：

```text
输入：当前截图图片
输出：识别出的文本
```

如果已有 OCR 服务返回的是结构化结果，例如：

```swift
RecognizedTextResult
OCRResult
TextRecognitionResult
[RecognizedTextLine]
[String]
```

请从中提取纯文本用于翻译。

如果已有 OCR 服务支持识别区域、行、段落、坐标信息，本需求第一版只需要使用文本内容，不要求做截图内覆盖翻译。

建议抽象调用逻辑：

```swift
let ocrResult = try await existingOCRService.recognizeText(from: image)
let sourceText = ocrResult.text
```

实际代码请根据项目中已有 OCR 服务的方法签名调整。

---

### 4. OCR 结果为空处理

如果 OCR 没有识别出文字，不要继续执行翻译。

需要展示用户可理解的提示：

```text
未识别到可翻译的文字
```

可以通过以下方式之一展示：

1. 弹出翻译结果窗口，并在窗口中显示空状态。
2. 使用现有 toast / HUD / alert 机制提示。
3. 使用当前项目已有错误提示组件。

要求：

1. 不崩溃。
2. 不继续调用翻译。
3. 不展示底层技术错误。
4. 用户能明确知道是“没有识别到文字”。

---

### 5. 本地翻译服务

新增或复用一个本地翻译服务。

建议命名：

```swift
LocalTranslationService
SystemTranslationService
AppleTranslationService
```

职责：

```text
输入 OCR 识别出的文字
输出翻译后的文字
```

建议接口：

```swift
func translate(
    text: String,
    targetLanguage: String
) async throws -> TranslationResult
```

或者：

```swift
func translate(
    text: String,
    sourceLanguage: String?,
    targetLanguage: String
) async throws -> TranslationResult
```

建议返回模型：

```swift
struct TranslationResult {
    let sourceText: String
    let translatedText: String
    let sourceLanguage: String?
    let targetLanguage: String
}
```

目标语言第一版默认使用：

```text
中文
```

如果项目已有用户语言设置，可以优先翻译成用户设置中的目标语言。

如果没有相关设置，第一版默认翻译为简体中文。

---

### 6. 本地语言识别

如果本地翻译能力支持自动识别源语言，可以不单独做语言识别。

如果本地翻译 API 需要明确源语言，可以使用项目已有语言识别逻辑，或使用系统本地语言识别能力。

建议优先级：

```text
1. 本地翻译能力自动识别源语言
2. 项目已有语言识别服务
3. 系统 NaturalLanguage 识别
4. 识别失败时 sourceLanguage 使用 nil / auto
```

语言识别失败不应该阻断整个流程。

---

### 7. 系统版本兼容

本地翻译能力可能存在系统版本要求。

实现时必须检查项目当前最低支持的 macOS 版本。

如果当前最低系统版本不支持本地翻译能力，需要做兼容处理。

示例逻辑：

```swift
if #available(macOS 15.0, *) {
    // 调用系统本地翻译能力
} else {
    // 展示不支持提示
}
```

实际可用版本请以 Xcode 和项目 SDK 编译结果为准。

低版本系统提示文案：

```text
当前系统暂不支持本地翻译，请升级 macOS 后重试。
```

要求：

1. 低版本系统不能崩溃。
2. 编译不能失败。
3. 不支持时要有用户可理解的提示。
4. 不要在低版本系统上强行调用不可用 API。

## 十一、与现有 AI 功能的关系

重要原则：

```text
隐藏 AI 入口，不删除 AI 能力。
新增本地翻译，不复用 AI 翻译。
复用已有 OCR，不重复实现 OCR。
```

要求：

1. 原 AI 服务保留。
2. 原 AI 配置保留。
3. 原 AI 分析能力保留。
4. 原 AI 翻译能力保留。
5. 原 AI 入口受 `showAIEntrances` 控制。
6. 新增的普通「翻译」按钮走纯本地流程。
7. 本地翻译流程不依赖 AI 配置。
8. 本地翻译流程不依赖会员、登录、订阅、后端接口。

## 十四、验收标准

### 1. AI 入口隐藏

* [ ] App 默认启动后，普通截图工具栏不显示 AI 入口。
* [ ] App 默认启动后，长截图工具栏不显示 AI 入口。
* [ ] 原 AI 功能代码没有被删除。
* [ ] 原 AI 服务没有被删除。
* [ ] 原 AI 配置没有被删除。
* [ ] 设置中开启「显示 AI 功能入口」后，普通截图工具栏可以重新显示 AI 入口。
* [ ] 设置中开启「显示 AI 功能入口」后，长截图工具栏可以重新显示 AI 入口。

## 十六、实现注意事项

1. 不要删除 AI 功能，只隐藏 AI 入口。
2. 不要重写已有 OCR 服务，直接复用。
3. 不要让普通「翻译」按钮走 AI pipeline。
4. 不要上传截图图片。
5. 不要上传 OCR 文本。
6. 不要调用后端接口。
7. 不要读取 AI API Key。
8. 不要检查 AI 订阅状态。
9. 不要因为本地翻译失败影响截图保存、复制、标注等其他功能。

11. 设置项命名要表达“显示入口”，不要表达“启用 AI”。
12. 推荐使用 `showAIEntrances` 作为设置 key。
13. 本地翻译失败时要有明确提示。
14. OCR 为空时要有明确提示。
15. 长截图和普通截图都要覆盖，不要只改其中一个。
16. 编译时要处理系统 API 可用性，避免低版本编译或运行问题。
