## 描述

TShot 是一款为 macOS 打造的原生截图工具。

它的目标不是做复杂庞大的截图平台，而是把日常最常用的截图动作做得更直接、更顺手。

你可以通过全局快捷键快速唤起截图，框选后立即进入编辑态，在同一条链路里完成复制、保存、标注、OCR、长截图或 Pin。

主要功能：

- 菜单栏常驻，随时唤起截图
- 支持全局快捷键触发
- 框选后立即进入截图编辑态
- 支持复制、保存、取消等常用操作
- 支持矩形、圆形、箭头、画笔、文字和马赛克标注
- 支持圆角与阴影样式调整
- 支持截图区域拖动与缩放微调
- 支持 OCR 识别，并将识别文本复制到剪贴板
- 支持 Pin，将截图固定为悬浮窗口查看
- 支持滚动长截图，连续拼接纵向内容

适合这些场景：

- 保存网页、文档、聊天记录等长内容
- 快速标出重点信息并发送给同事或朋友
- 提取截图中的文字，减少手动录入
- 把参考截图固定在桌面一角，对照处理当前工作

TShot 使用 Apple 原生技术构建，围绕 macOS 的截图与系统工作流进行设计，尽量保持轻量、直接、易理解。
