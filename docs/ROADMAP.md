### Sprint 32

长截图 OCR / AI

状态：
✅ Done

成果：

- 长截图底部操作面板增加 `OCR` 与 `AI` 入口
- 支持基于当前长图结果直接执行 `OCR` 与 `AI`

- `AI` 分析窗口在屏幕空间不足时支持底部按钮自动换行

### Sprint 34

状态：
✅ Done

成果：

- 控制台已补充链路日志，可明确区分当前走的是本地 OCR 还是视觉取字
